# Security

## Report privately

Email [support@doubleagent.so](mailto:support@doubleagent.so) with "security" in the subject for:

- a way to make the recorder leak keys, raw subject identifiers or content it should not send,
- a way to make it throw into, block or crash the agent it runs in,
- anything that lets one party forge another's telemetry.

Include the package version, a minimal reproduction and what you saw. Do not open a public issue with a working
exploit. We will reply, agree on a fix and a disclosure date, and credit you unless you prefer otherwise.

## Scope

This repository is the client-side recorder and its adapters. Reports about the hosted Double Agent service are
welcome at the same address.
